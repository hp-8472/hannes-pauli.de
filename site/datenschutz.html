Farbdarstellung

Wenn Sie „Dunkel“ oder „Hell“ wählen, speichert Ihr Browser die Auswahl lokal, damit sie beim nächsten Besuch erhalten bleibt. Diese Einstellung wird nicht an einen Server gesendet. Mit „System“ entfernen Sie die gespeicherte Auswahl und folgen wieder der Geräteeinstellung.

Sprachauswahl

Beim Aufruf der Startseite wird die bevorzugte Browsersprache lokal ausgewertet: Deutsch bleibt Deutsch, andere Sprachen führen zur englischen Fassung. Wenn Sie über DE oder EN selbst eine Sprache auswählen, speichert Ihr Browser diese Einstellung für spätere Besuche. Die automatische Erkennung speichert keine Auswahl. Es wird kein Übersetzungsdienst eingebunden und die Spracheinstellung wird nicht gesondert an einen Server gesendet. Sie können die gespeicherte Auswahl über die Websitedaten Ihres Browsers löschen.
